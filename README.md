# GCTU Campus Navigator

A campus navigation web application for Ghana Communication Technology University (GCTU), Tesano Campus, Accra, Ghana.

## About

This app helps students and visitors navigate the GCTU Tesano campus with ease, providing an interactive map, building search, and turn-by-turn directions between key campus locations. It also includes a help desk feature for submitting support requests, with an admin dashboard for managing and resolving tickets.

## Features

- **Interactive campus map** — view all buildings and points of interest using Leaflet/OpenStreetMap
- **Building search** — quickly find any building or location by name
- **Navigation** — get routes and turn-by-turn directions between campus locations
- **Live geolocation** — see your current position on the map
- **Help desk** — submit support tickets, browse FAQs, and view department contacts
- **Admin dashboard** — secure, authenticated access for staff to manage and respond to help desk tickets
